# Gravita Recycling Platform

Modern B2B waste material trading platform with beautiful UI/UX.

## Quick Start

### Backend
```bash
cd backend
npm run start:dev
```

### Frontend
```bash
cd frontend
flutter run
```

### Create Test User
```bash
cd backend
./create-test-user.sh
```

**Test Credentials:**
- Email: `admin@gravita.com`
- Password: `password123`

## Tech Stack

**Frontend:** Flutter + Riverpod + Glassmorphism
**Backend:** NestJS + Prisma + PostgreSQL
**Auth:** JWT tokens
